# 올바른이사 운영 전 최종 체크리스트

## 1. 도메인과 Vercel
- 실제 도메인 연결
- Vercel `NEXT_PUBLIC_SITE_URL`을 실제 https 도메인으로 설정
- www 사용 여부 결정 후 하나로 리디렉션
- HTTPS 정상 적용 확인

## 2. 검색엔진
- `/robots.txt` 확인
- `/sitemap.xml` 확인
- Google Search Console 등록
- 네이버 서치어드바이저 등록
- 대표 도메인 기준 canonical 확인
- 주요 지역 페이지의 title/description 중복 여부 표본 점검

## 3. 지역 페이지 이미지
`lib/region-assets.ts`에서 각 페이지 대표 이미지 URL을 관리합니다.

예시:
```ts
"seoul/강남구": "https://이미지주소/gangnam.webp"
```

권장 이미지 기준:
- 가로형 1200×800 또는 유사 비율
- WebP 권장
- 지역의 실제 주거·도로·생활권 분위기를 보여주는 이미지
- 지역명만 바꾼 동일 이미지의 과도한 반복은 피하기

## 4. 비교견적 DB
- Supabase 프로젝트 생성
- `SUPABASE_URL` 서버 환경변수 등록
- `SUPABASE_SERVICE_ROLE_KEY` 서버 환경변수 등록
- `supabase/moving_estimates.sql` 실행
- 테스트 접수 후 DB 저장 여부 확인

비밀키는 GitHub 코드나 브라우저 환경변수에 넣지 않습니다.

## 5. 관리자
- 관리자 인증 연결 전 고객 접수 데이터 목록을 공개하지 않기
- 인증 후 접수 상태: 신규 → 상담중 → 견적완료 → 완료/취소
- 전화번호 등 개인정보는 관리자 전용 화면에서만 확인

## 6. 개인정보 및 운영자 정보
서비스 오픈 전에 다음 항목을 실제 운영정보로 확정합니다.
- 운영자 또는 사업자 명칭
- 사업자등록번호(해당하는 경우)
- 주소 및 대표 연락처
- 개인정보 보호책임자 및 문의 연락처
- 개인정보 보관기간
- 제휴 이사업체에 전달되는 정보와 제공 목적

## 7. 모바일 점검
최소 아래 화면 폭에서 확인합니다.
- 375px
- 430px
- 768px
- 1024px
- 데스크톱 1440px 이상

확인 항목:
- 상단 H1 줄바꿈
- 손없는날 달력 셀 겹침
- 날씨 정보 넘침
- 지역 대표 이미지 비율
- 비교견적 다음/이전 버튼 터치 영역
- FAQ와 지역 내부링크

## 8. 콘텐츠 품질
지역 페이지는 단순 지역명 치환 페이지로 운영하지 않습니다.
- 생활권별 주거형태
- 차량 진입과 주차
- 산업·관광·산간·해안 등 지역 특성
- 관리사무소 및 공동주택 체크사항
- 실제 이동시간에 영향을 주는 요소
을 지역마다 다르게 유지합니다.

법률·행정·요금 정보는 변경될 수 있으므로 정부24, 법원 인터넷등기소, 한국전력, 지역 도시가스 등 공식 기관 최신 정보를 기준으로 주기적으로 점검합니다.
